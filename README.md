# Proyecto de Gestión de Información

Este proyecto es una aplicación desarrollada en Python que permite gestionar información almacenada en un archivo JSON. Incluye funcionalidades para visualizar, editar y manipular los datos.

## Estructura del Proyecto

El proyecto está organizado en las siguientes carpetas y archivos:

- `guardar_informacion.json`: Archivo donde se almacenan los datos gestionados por la aplicación.
- `Proyecto_Git_correa1jedoer1florez2heidy2/`
  - `README.md`: Documento con información básica del proyecto.
  - `main.py`: Archivo principal que ejecuta la aplicación.
  - `datos.py`: Módulo encargado de la gestión de datos.
  - `visualisar.py`: Script para visualizar la información almacenada.
  - `modulos/`
    - `editar.py`: Módulo para la edición de datos.
    - `funcionalidad.py`: Contiene funciones auxiliares para la gestión de datos.
  - `__pycache__/`: Carpeta con archivos compilados en Python.

## Requisitos

Para ejecutar este proyecto, necesitas:

- Python 3.12 o superior.
- Un editor de código como VS Code o PyCharm.

## Instalación y Uso

1. Clonar o descargar el repositorio.
2. Asegurarse de tener Python instalado.
3. Abrir una terminal en la carpeta del proyecto y ejecutar:
   ```sh
   python main.py
   ```
4. Seguir las instrucciones en pantalla para gestionar los datos.

## Funcionalidades

- **Visualización de datos**: Permite ver la información almacenada en `guardar_informacion.json`.
- **Edición de datos**: Modifica la información existente.
- **Gestión modular**: Utiliza módulos separados para distintas funcionalidades.
